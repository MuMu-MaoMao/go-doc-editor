# 00 · 项目历史沿革

> 本文档记录 go-doc-editor 项目在引入规范体系**之前**的历史演进过程。
> 项目根目录下的旧文档是各阶段的设计思路和决策记录，
> 已按新规范提炼为 ADR（架构决策记录），旧文档保留作为历史参考。

---

## 历史阶段总览

### 阶段一：项目初始化

建立基础 Web 服务，支持文档的 CRUD 操作（基于本地文件系统）。

**相关文档**：`readme.md`（基础架构描述）

### 阶段二：添加用户认证

实现 JWT 登录/注册、用户隔离的文档存储、密码加密。

| 项目 | 内容 |
|------|------|
| 旧文档 | [`添加新功能.md`](../添加新功能.md) |
| 对应 ADR | [ADR-001: 用户认证架构决策](./adr/ADR-001-use-jwt-auth.md) |
| 核心变更 | `internal/auth/`、`internal/user/`、`internal/middleware/`、`static/login.html`、`static/register.html` |

### 阶段三：AI 集成（后端代理）

接入 DeepSeek API，后端代理调用，SSE 流式返回前端。

| 项目 | 内容 |
|------|------|
| 旧文档 | [`AI集成方案.md`](../AI集成方案.md) |
| 对应 ADR | [ADR-002: AI 后端代理架构决策](./adr/ADR-002-deepseek-proxy.md) |
| 核心变更 | `internal/service/ai_service.go`、`internal/handler/ai_handler.go`、`static/ai-chat.js` |

### 阶段四：AI 对话优化

针对 AI 对话功能的四个痛点（对话历史、Markdown 渲染、面板拉伸、附带文档）进行优化。

| 项目 | 内容 |
|------|------|
| 旧文档 | [`AI对话优化方案.md`](../AI对话优化方案.md) |
| 对应 ADR | [ADR-003: AI 对话历史管理方案](./adr/ADR-003-chat-history-management.md) |
| 对应 ADR | [ADR-004: 前端 Markdown 渲染与 XSS 防护方案](./adr/ADR-004-markdown-rendering.md) |
| 核心变更 | `static/ai-chat.js`、`static/editor.html`、`static/style.css`、`internal/handler/ai_handler.go`、`internal/service/ai_service.go` |

### 阶段五：建立开发规范

引入完整的开发流程规范体系，包括分支策略、代码风格、架构规范、测试要求等。

| 项目 | 内容 |
|------|------|
| 规范文档 | `docs/01` ~ `docs/12` 系列文档 |
| 索引入口 | [docs/INDEX.md](./INDEX.md) |
