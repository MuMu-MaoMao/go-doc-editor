# 08 · 测试要求

> 本文档定义 go-doc-editor 的测试策略、覆盖目标和编写规范。
> **编写或运行测试用例时**请参考本文档。

---

## 8.1 测试层级

```
层级 1：单元测试    → Service 层核心逻辑（优先级最高）
层级 2：集成测试    → Handler → Service → 文件系统链路
层级 3：E2E 测试    → 浏览器交互（可选，后期补充）
```

## 8.2 测试文件位置

测试文件与源码放在**同一包**下，文件名以 `_test.go` 结尾：

```
internal/service/
├── file_service.go
├── file_service_test.go      # 单元测试
├── ai_service.go
└── ai_service_test.go        # 单元测试

internal/handler/
├── file_handler.go
├── file_handler_test.go      # 集成测试
├── auth_handler.go
└── auth_handler_test.go      # 集成测试
```

## 8.3 Service 层测试（优先级最高）

Service 层是业务逻辑核心，必须优先覆盖。

### 测试模式：表驱动测试

```go
package service

import (
    "os"
    "path/filepath"
    "testing"
)

func TestSafeFilePath(t *testing.T) {
    svc := NewFileService(t.TempDir())

    tests := []struct {
        name     string
        username string
        filename string
        wantErr  bool
    }{
        {"valid filename", "user1", "test.txt", false},
        {"path traversal", "user1", "../../etc/passwd", true},
        {"empty filename", "user1", "", true},
        {"contains slash", "user1", "a/b.txt", true},
        {"contains backslash", "user1", "a\\b.txt", true},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            _, err := svc.safeFilePath(tt.username, tt.filename)
            if (err != nil) != tt.wantErr {
                t.Errorf("safeFilePath() error = %v, wantErr = %v", err, tt.wantErr)
            }
        })
    }
}
```

### Service 层测试要点

- 使用 `t.TempDir()` 创建临时目录，测试自动清理
- 覆盖**正常路径**和**错误路径**
- 边界条件：空字符串、特殊字符、超长文件名

## 8.4 Handler 层测试

使用 `net/http/httptest` 包：

```go
package handler

import (
    "context"
    "net/http"
    "net/http/httptest"
    "testing"

    "go-doc-editor/internal/middleware"
    "go-doc-editor/internal/service"
)

func TestListFilesHandler(t *testing.T) {
    // Arrange
    svc := service.NewFileService(t.TempDir())
    handler := NewFileHandler(svc)

    // 注入 JWT context（模拟已认证用户）
    ctx := context.WithValue(
        httptest.NewRequest("GET", "/api/files", nil).Context(),
        middleware.UserContextKey,
        "testuser",
    )
    req := httptest.NewRequest("GET", "/api/files", nil).WithContext(ctx)
    w := httptest.NewRecorder()

    // Act
    handler.ListFiles(w, req)

    // Assert
    resp := w.Result()
    if resp.StatusCode != http.StatusOK {
        t.Errorf("expected 200, got %d", resp.StatusCode)
    }
}
```

### Handler 层测试要点

- 通过 context 注入测试用户名（绕过 JWT 验证）
- 验证 HTTP 状态码和响应体 JSON 结构
- 使用 `httptest.NewRecorder()` 捕获响应

## 8.5 Auth / Middleware 测试

```go
package middleware

import (
    "net/http"
    "net/http/httptest"
    "testing"
)

func TestAuthMiddleware_MissingHeader(t *testing.T) {
    handler := AuthMiddleware(func(w http.ResponseWriter, r *http.Request) {
        t.Error("handler should not be called")
    })

    req := httptest.NewRequest("GET", "/api/files", nil)
    w := httptest.NewRecorder()
    handler(w, req)

    if w.Code != http.StatusUnauthorized {
        t.Errorf("expected 401, got %d", w.Code)
    }
}
```

## 8.6 覆盖率目标

|----|---------|---------|
| `internal/service/` | 70%+ | 85%+ |
| `internal/handler/` | 50%+ | 70%+ |
| `internal/auth/` | 80%+ | 90%+ |
| `internal/middleware/` | 80%+ | 90%+ |

## 8.7 测试运行命令

```bash
# 运行所有测试
go test ./... -v

# 运行并检查竞态条件
go test ./... -race

# 生成覆盖率报告
go test ./... -coverprofile=coverage.out
go tool cover -html=coverage.out

# 运行单个包的测试
go test ./internal/service/ -v -run TestSafeFilePath
```
