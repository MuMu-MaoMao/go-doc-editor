## 📋 常见场景速查

| 你正在做的事情 | 需要查阅的文档 |
|---------------|--------------|
| **启动一个新功能** | **`12-功能开发流程`**（首选）→ 选择范式 A/B/C 按步骤执行即可 |
| **写新功能代码（已有设计）** | `04-代码风格` → `05-架构规范` |
| **提交代码** | `03-提交信息规范` |
| **发起 PR** | `07-代码审查流程` + `03-提交信息规范` |
| **审查别人代码** | `07-代码审查流程` |
| **修复一个 Bug** | 按范式 B → `04-代码风格` → `08-测试要求` |
| **集成新 AI 模型** | 按范式 A → `10-AI集成开发规范` + `05-架构规范` |
| **留开发日志** | `12-功能开发流程规范` → Log 日志规范章节 |
| **发布新版本** | `09-发布与版本管理` |
| **做架构决策** | `06-文档标准`（ADR 章节）|
| **新成员入职** | `01-总体原则` → `12-功能开发流程` → `02-Git分支策略` → `03-提交信息规范` → `04-代码风格` |
| **写单元测试** | `08-测试要求` |
| **不确定技术方案是否可行** | 按范式 C → 先实验验证，再决定是否正式开发 |
