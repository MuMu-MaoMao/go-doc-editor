## 决策记录

- 角色列表接口 `/api/ai/roles` **不需要 JWT 认证**，因为角色信息是公开的
- 切换角色时会**清空对话历史**（因为 system prompt 变了，旧上下文不适用）
- 角色选择 UI 使用 `<select>` 下拉框，简单且兼容性好
- 所有角色的 systemPrompt 保存在后端，前端通过 API 获取
