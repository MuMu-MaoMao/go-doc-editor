### 审查后确认的设计选择

| 选择 | 理由 |
|------|------|
| 角色列表 API 无需认证 | 角色信息是公开的（角色名、描述），不含敏感数据 |
| 切换角色清空对话 | 因为 system prompt 变了，旧消息的上下文已不适用 |
| systemPrompt 只存后端 | 符合安全规范，避免前端暴露 |
| 使用 `<select>` 下拉框 | 简单、兼容性强、滚动友好 |
| 使用 `setInterval` 轮询等待角色加载 | 避免回调嵌套过深，页面加载后立即执行 |
