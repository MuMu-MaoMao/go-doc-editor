## 功能描述

在 AI 对话面板中新增角色扮演功能按钮，提供一组预设角色（如"专业编辑"、"幽默文案师"、"严格导师"、"友善读者"等），用户选择一个角色后，AI 以该角色的身份对文档内容进行评价和建议。

## 需求来源

你提出：让项目里的 AI 功能新添一个角色扮演功能按钮，即提供几个角色让 AI 扮演并对文档内容进行评价。

## 动机与目标

| 目标 | 说明 |
|------|------|
| 满足不同评价视角 | 用户可以根据需要让 AI 以不同身份给出反馈 |
| 增强功能趣味性 | 角色扮演让 AI 交互更有趣、更生动 |
| 零学习成本 | 一键选择角色，无需手动输入 system prompt |

## 初步接受标准

- [ ] 至少有 4 个预设角色可选
- [ ] 切换角色后 AI 的回答风格明显不同
- [ ] 角色选择 UI 简洁直观（下拉框或卡片选择器）
- [ ] 支持以后再添加新角色（角色定义在后端）
- [ ] 当前角色状态在对话中清晰显示
- [ ] 更换角色后 system prompt 实时更新
