## 功能描述

对 AI 对话面板的交互体验进行三项优化，让窗口操作更自然、角色选择器更美观统一。

## 三项需求

### 需求一：按住对话框上部拖动

AI 面板当前是 `position: fixed` 固定定位，用户无法移动其位置。
需要实现：**鼠标按住 AI 面板的头部区域（header）拖动，面板跟随移动**。

**预期效果**：类似操作系统窗口的拖拽行为，拖拽时面板平滑跟随鼠标。

### 需求二：按住边框拉伸大小

AI 面板当前使用 CSS `resize: both` 实现大小调整，
但用户必须精确地将鼠标移动到右下角才能拉伸，操作区域小、体验差。

需要实现：**鼠标按住面板任意边框（上/下/左/右）或四角均可拉伸**。

**预期效果**：鼠标移到面板边框时变为对应的双向箭头光标，
按住后拖动即可调整面板大小，无需精确对准右下角。

### 需求三：角色选择器 UI 美化与移位

当前角色选择器位于 AI 面板头部下方的一条独立区域（`.ai-chat-role-bar`），
样式为普通 `<select>` 下拉框。

需要改进为：
1. **移至输入工具栏**，与"📎 附带文档"按钮并列
2. **风格统一为小圆角方框**（类似 Claude Code 应用的按钮风格）
3. **功能逻辑仍为下拉框**，但视觉上融合为工具栏按钮组的一部分

**预期效果**：输入框上方呈现两个并列的按钮风格控件：
- [📎 附带文档]（已有，保持 toggle 逻辑不变）
- [🎭 专业编辑 ▼]（角色选择器，显示当前角色名，点击展开下拉）

## 动机与目标

| 目标 | 说明 |
|------|------|
| 提升窗口操作体验 | 拖拽+边框拉伸让用户自由布置工作区 |
| 降低操作门槛 | 边框拉伸比右下角拖拽更易用 |
| UI 视觉统一 | 角色选择器融入工具栏，风格一致 |

## 初步接受标准

- [ ] 鼠标按住 AI 面板头部可拖动整个面板
- [ ] 拖拽不超出视口边界（或至少不丢失面板）
- [ ] 鼠标移到边框时显示对应 resize 光标
- [ ] 按住任意边框均可拉伸面板大小
- [ ] 角色选择器与"附带文档"按钮并列在同一行
- [ ] 角色选择器按钮显示当前角色名 + 下拉箭头
- [ ] 角色选择器按钮样式与"附带文档"按钮一致（圆角方框）
- [ ] 所有现有功能（发送消息、附带文档、角色切换）不受影响
