## Task 2: 存储层 — 实现 docstore 包 ✅

**文件**: `internal/docstore/doc_store.go`（新增）

实现了 `Store` 结构体，4 个 CRUD 方法：

| 方法 | SQL 操作 | 说明 |
|------|---------|------|
| `ListFiles` | `SELECT filename ... WHERE username = ? ORDER BY filename ASC` | 返回空数组（非 null） |
| `ReadFile` | `SELECT content ... WHERE username = ? AND filename = ?` | 不存在返回 ErrFileNotFound |
| `SaveFile` | `INSERT ... ON DUPLICATE KEY UPDATE` | upsert 语义 |
| `DeleteFile` | `DELETE ... WHERE username = ? AND filename = ?` | 影响 0 行返回 ErrFileNotFound |

**关键设计**：
- 与 `user.Store` 采用相同模式
- 哨兵错误 `ErrFileNotFound`（"文件不存在"）确保与 handler 层错误字符串匹配兼容
- 全部使用参数化查询
