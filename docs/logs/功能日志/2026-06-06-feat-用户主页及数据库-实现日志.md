## 数据库表结构

```sql
users (username PK, password_hash, created_at)
login_logs (id PK AUTO_INCREMENT, username FK, login_time)
```

## 启动命令

```bash
go run cmd/server/main.go --ai-key=你的key -mysql-dsn "root:13579@tcp(localhost:3306)/godoxedit?charset=utf8mb4&parseTime=true"
```
