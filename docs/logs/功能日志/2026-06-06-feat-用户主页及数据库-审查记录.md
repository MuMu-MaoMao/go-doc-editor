## 启动方式变更

```bash
go run cmd/server/main.go \
    --ai-key=你的key \
    -mysql-dsn "root:13579@tcp(localhost:3306)/godoxedit?charset=utf8mb4&parseTime=true"
```

注意：
1. 需要先手动 `go mod tidy`（Linux 环境没有 Go 编译器）
2. 首次启动会自动建表
3. 旧的 JSON 用户数据需要重新注册（或先手动插入 MySQL）
