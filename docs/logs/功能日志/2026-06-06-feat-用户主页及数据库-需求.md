## 功能描述

### 需求一：MySQL 数据库替代 JSON 文件存储

当前用户数据存储在 JSON 文件中（`data/users.json`），没有注册时间记录，
也无法追踪登录历史。需要迁移到 **MySQL** 数据库，建立标准化的用户表和登录日志表。

**数据库信息**：
| 项目 | 值 |
|------|-----|
| MySQL 版本 | 8.0.44 |
| 主机 | localhost |
| 端口 | 3306 |
| 用户名 | root |
| 密码 | 13579 |
| 数据库名 | godoxedit |

### 需求二：右上角圆形用户按钮

在 `index.html`（登录后）和 `editor.html` 的右上角新增一个圆形按钮，
带有人形图标（👤），点击跳转到用户主页。

### 需求三：用户主页

新增一个简单的用户主页（`profile.html`），展示：
- 用户名
- 注册时间（从数据库读取）
- 最近登录时间
- 登录历史列表

## 动机与目标

| 目标 | 说明 |
|------|------|
| 数据规范化 | JSON 文件无法支持多表关联和查询 |
| 用户时间追踪 | 记录注册时间和登录历史 |
| 用户可见信息 | 让用户看到自己的账户信息 |

## 初步接受标准

- [ ] MySQL 数据库连接成功，应用启动时自动初始化表结构
- [ ] 用户注册时写入 MySQL（用户名、bcrypt 密码、注册时间）
- [ ] 用户登录时写入登录日志表
- [ ] 现有用户数据从 JSON 迁移到 MySQL（或提供迁移工具）
- [ ] 右上角圆形用户按钮在 index 和 editor 页面均可见
- [ ] 用户主页显示用户名、注册时间、最近登录时间、登录列表
- [ ] 所有现有功能（文件 CRUD、AI 对话）不受影响
