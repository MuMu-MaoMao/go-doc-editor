## 功能描述

用户可按"大类 → 中类 → 小类"手动创建三级分类树，将文档归属到任意一级分类下。前端侧边栏展示分类树，支持展开/收起，点击分类筛选文档。

## 动机与目标

- 用户需要按自己的知识体系组织文档
- 分类是知识收纳的基础能力，后续的标注/关联功能依赖于此
- 解决"所有文档平铺列表"的无序感

## 初步接受标准

- [ ] 用户可创建/修改/删除分类（大类→中类→小类）
- [ ] 最多三级，禁止创建第四级
- [ ] 用户可将文档设置到某个分类下
- [ ] 分类以树形结构展示（前端侧边栏）
- [ ] 点击分类筛选出该分类下的文档
- [ ] 未分类的文档有单独的入口
- [ ] 所有 API 遵循现有认证方式（JWT）
