# 前端 UI 优化总结（2026-06-07）

> 对编辑器前端进行全面 UI 优化，覆盖设计系统重构、交互重构、新功能适配三大方向。

---

## 一、设计系统重构

### CSS 变量体系
将原有分散的样式值统一定义为 `:root` 变量，覆盖颜色、阴影、圆角、字体四大类：

- **颜色**：`--bg-body`, `--bg-sidebar`, `--text-primary`, `--border` 等 20+ 变量
- **阴影**：4 级阴影系统 `--shadow-sm/md/lg/xl`
- **圆角**：`--radius-xs/sm/md/lg/xl` 统一曲线
- **字体**：`--font-sans` / `--font-mono` 统一字族

### 布局优化
- 侧边栏三大区块（分类/文件/标注）使用 `flex-grow` 自动分配高度
- 主布局锁定 `height: calc(100vh - ...)` 消除滚动条抖动
- 响应式断点从 680px 提升到 800px，覆盖更多设备

---

## 二、交互重构

### 分类树折叠
- 点击 ▶/▼ 箭头折叠/展开子分类（类似 VS Code）
- 折叠状态用 `Set` 管理，不影响后端数据
- 不同层级用左侧色条 + 缩进区分

### 全局最小化
- 工具栏「—」按钮或右下角 ⚫ 按钮隐藏/显示整个编辑器
- 淡出动画 `opacity + transform + visibility`（0.35s）
- 按钮和 AI 按钮可拖拽（仅最小化时）
- 展开时按钮丝滑弹回原位（`cubic-bezier(0.34, 1.56, 0.64, 1)` 弹簧曲线）
- 拖拽后释放不会误触功能（`stopImmediatePropagation` 拦截）
- 拖拽位置在最小化/展开切换间保持

### 按钮拖拽引擎
- `mousedown` 开始，`mousemove` 实时跟踪，`mouseup` 结束
- 拖拽时 `transition: none` 消除延迟
- `didDrag` 标记区分点击与拖拽

### 内联样式清理
- 所有 `style="..."` 替换为有意义的 class 名
- 标注弹出气泡使用 `popIn` 缩放动画
- 标注列表改用卡片式条目

---

## 三、图标处理

### 去 emoji 化
侧边栏和工具栏中所有 emoji 图标（📂📄📌🔗✏️💾 等）替换为：

| 元素 | 替换方案 |
|------|---------|
| 分类树 | 左侧色条 + 层级缩进 + 折叠箭头 ▶/▼ |
| 标题 | 纯文字 uppercase |
| 交互按钮 | 纯文字（保存 / 标注 / 删除 / 问 AI） |
| 浮动按钮 | 全黑圆形 ⚫ / 💬 |

---

## 四、变更文件

| 文件 | 变更 |
|------|------|
| `static/style.css` | 完全重写设计系统：变量化+布局重构+分类树折叠+最小化+拖拽 |
| `static/editor.html` | 清理全部 inline style，新增最小化/展开按钮结构 |
| `static/editor.js` | 折叠渲染逻辑、全局最小化/展开切换、拖拽引擎 |

## 五、体验对比

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 分类树 | emoji 文件夹 + 扁平列表 | 色条分层 + 折叠箭头 + 可折叠 |
| 窗口 | 只有 AI 面板可收 | 整个编辑器可隐藏，按钮可拖拽 |
| 图标 | emoji 混杂 | 纯文字/纯几何风格统一 |
| 动效 | 无 | 淡入、弹跳、弹簧过渡 |
| 样式内联 | 多处 `style=""` 散落 | 全部归入 CSS class |
