### Phase 2：功能实现

---

#### Task 3：角色选择器自定义下拉按钮

**描述**：在 `ai-chat.js` 中实现自定义下拉按钮替代原有 `<select>`：
1. 移除原有 `<select>` 的事件绑定
2. 按钮点击展开/收起下拉列表
3. 下拉选项列表（浮动层）
4. 点击选项切换角色
5. 点击外部关闭下拉列表
6. 保持 `switchToRole` 接口不变

**接受标准**：
- [ ] 按钮显示 `🎭 {当前角色名} ▼`
- [ ] 点击按钮弹出下拉列表
- [ ] 每项显示角色名 + 简短描述
- [ ] 点击选项切换角色并关闭下拉
- [ ] 点击外部区域关闭下拉
- [ ] 切换角色后按钮文本更新

**验证方式**：
- [ ] 手动测试角色选择功能

**涉及文件**：
- `static/ai-chat.js`

**预计范围**：中（1 个文件，~50 行）

---

#### Task 4：面板拖拽功能

**描述**：在 `ai-chat.js` 中实现拖拽面板功能：
1. mousedown 在 header 上记录偏移（排除按钮）
2. mousemove 更新面板 left/top
3. mouseup 停止拖拽
4. 边界约束（防止拖出视口）
5. 拖拽时禁用 CSS transition

**接受标准**：
- [ ] 按住 header 任意位置可拖动
- [ ] 点击 header 上的按钮（关闭、清空）不触发拖拽
- [ ] 拖拽流畅不卡顿
- [ ] 面板不会完全拖出视口

**验证方式**：
- [ ] 手动拖拽测试

**涉及文件**：
- `static/ai-chat.js`

**预计范围**：中（1 个文件，~40 行）

---

#### Task 5：面板边框拉伸功能

**描述**：在 `ai-chat.js` 中实现边框拉伸功能：
1. mousemove 检测鼠标距边缘 < 8px → 切换光标
2. mousedown 在边缘 → 记录方向开始拉伸
3. mousemove 根据方向调整宽高和位置
4. mouseup 停止拉伸
5. 约束最小/最大尺寸

**接受标准**：
- [ ] 鼠标移到上/下/左/右边框 8px 内切换对应光标
- [ ] 鼠标移到四角切换对应光标
- [ ] 按住边框拖动可拉伸面板
- [ ] 最小不低于 320x400
- [ ] 最大不超过 750x90vh

**验证方式**：
- [ ] 手动拉伸测试各方向

**涉及文件**：
- `static/ai-chat.js`

**预计范围**：中（1 个文件，~80 行）
