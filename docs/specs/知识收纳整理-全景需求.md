## 产品定位

从"文档编辑器"转型为**知识收纳整理工具**。核心价值不再是"写文档"，而是**存储和组织知识**——让文档与文档之间产生关联，形成知识网络。

## 功能全景图

```
知识收纳整理系统
│
├── ① 三级分类体系（Phase 1）
│   ├── 大类（category）— 顶层分类，如"技术"、"生活"、"工作"
│   ├── 中类（sub_category）— 二级分类，如"技术/Go语言"、"技术/前端"
│   └── 小类（sub_sub_category）— 三级分类，如"技术/Go语言/并发编程"
│   └── 文档可归属到任意一级分类下
│
├── ② 关键语句标注与跨文档关联（Phase 2）
│   ├── 用户在文档中选中一段文字 → 添加标注（annotation）
│   ├── 标注可以关联到另一个文档
│   ├── 标注可以附带用户的评语/想法
│   └── 在目标文档中可以看到"被引用于"的提示
│
└── ③ 前端交互适配（贯穿 Phase 1 & 2）
    ├── 编辑器侧边栏：分类树形浏览
    ├── 文档属性面板：选择/切换分类
    └── 标注操作：选中文字弹出标注按钮
```

## 全局接受标准

- [ ] 用户可创建三级分类（大类 → 中类 → 小类）
- [ ] 用户可将文档归属到任意一级分类下
- [ ] 分类以树形结构展示（前端侧边栏）
- [ ] 用户可选中文档中的文字→添加标注→关联到其他文档
- [ ] 被关联的文档页有"被引用于"的提示
- [ ] 所有数据存储在 MySQL 数据库中
- [ ] 现有文档 CRUD 功能完全不受影响

## 风险与注意事项

| 风险 | 缓解措施 |
|------|---------|
| Phase 0 数据库重构可能影响现有功能 | 新增表不动旧表，现有 documents 表完全保留 |
| 标注功能需要前端富文本选区 API | 使用 `window.getSelection()` + Range API |
| 三级分类层级深，前端树形渲染 | 保持简单，先不做无限层级拖拽，固定三级 |
