# 知识收纳整理 — 全局数据模型设计

> **关联全景需求**: `docs/specs/知识收纳整理-全景需求.md`
> **关联子单元划分**: `docs/specs/知识收纳整理-子单元划分.md`

---

## 设计原则

1. **旧表尽量不动**：`users`、`login_logs`、`ai_keys` 完全不变
2. **documents 加字段**：直接加 `category_id` 字段替代关联表，简化查询
3. **用户隔离**：所有表都包含 `username` 字段，通过参数化查询过滤
4. **简洁优先**：三级分类用 parent_id 递归实现，应用层限制最多三级

---

## 表变更总览

| 操作 | 表名 | 说明 |
|------|------|------|
| 🖊 修改 | `documents` | 新增 `category_id` 字段 + 索引 |
| 🆕 新建 | `categories` | 三级分类树（大类→中类→小类） |
| 🆕 新建 | `annotations` | 关键语句标注与跨文档关联 |

---

## 详细设计

### 1. documents — 加一个字段

```sql
ALTER TABLE documents
  ADD COLUMN category_id BIGINT DEFAULT NULL COMMENT '所属分类ID（NULL=未分类）',
  ADD INDEX idx_doc_category (username, category_id);
```

**设计说明**：

| 决策 | 选择 | 理由 |
|------|------|------|
| 一篇文章几个分类 | **一个** | 简化设计，用 documents 的 category_id 字段即可，无需关联表 |
| 为什么不用新表 | 直接加字段 | 节省一次 JOIN，查询更快，逻辑更简单 |
| 是否加外键约束 | 不加 | MySQL 外键影响性能，应用层保证数据一致性 |

**查询示例**：
```sql
-- 查找某个分类下的所有文档（无需 JOIN）
SELECT filename FROM documents
WHERE username = ? AND category_id = ?
ORDER BY updated_at DESC;

-- 查找某文档的分类（直接读 category_id 字段）
SELECT category_id FROM documents WHERE username = ? AND filename = ?;

-- 查找未分类的文档
SELECT filename FROM documents WHERE username = ? AND category_id IS NULL;
```

### 2. categories — 分类树（不变）

```sql
CREATE TABLE categories (
    id         BIGINT       AUTO_INCREMENT PRIMARY KEY COMMENT '分类ID',
    username   VARCHAR(255) NOT NULL        COMMENT '所属用户',
    name       VARCHAR(100) NOT NULL        COMMENT '分类名称',
    parent_id  BIGINT       DEFAULT NULL    COMMENT '父分类ID（NULL=顶级大类）',
    sort_order INT          NOT NULL DEFAULT 0 COMMENT '排序序号，同级内排序',
    created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_cat_username (username),
    INDEX idx_cat_parent (username, parent_id),
    UNIQUE INDEX idx_cat_name_unique (username, parent_id, name) COMMENT '同级下分类名唯一'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='三级分类树';
```

**设计说明**：

| 设计决策 | 选择 | 理由 |
|---------|------|------|
| 层级实现 | `parent_id` 自引用 | 未来可扩展为无限层级 |
| 三级限制 | 应用层校验 | 数据库不做硬限制，由 service 层检查 |
| 同级同名限制 | `UNIQUE(username, parent_id, name)` | 同一用户同层级不重名 |

**层级校验规则（应用层）**：
- level 1（大类）：`parent_id IS NULL`
- level 2（中类）：`parent_id` 指向一个大类
- level 3（小类）：`parent_id` 指向一个中类
- 禁止创建 level 4+

### 3. annotations — 关键语句标注与跨文档关联（不变）

```sql
CREATE TABLE annotations (
    id               BIGINT       AUTO_INCREMENT PRIMARY KEY COMMENT '标注ID',
    username         VARCHAR(255) NOT NULL        COMMENT '所属用户',
    source_filename  VARCHAR(255) NOT NULL        COMMENT '来源文档名（从哪篇文档选的文字）',
    selected_text    TEXT         NOT NULL        COMMENT '选中的关键语句原文',
    target_filename  VARCHAR(255) DEFAULT NULL    COMMENT '关联的目标文档名（可为空）',
    comment          TEXT                         COMMENT '用户的评语/想法',
    position_start   INT          NOT NULL DEFAULT 0 COMMENT '选中文本起始偏移',
    position_end     INT          NOT NULL DEFAULT 0 COMMENT '选中文本结束偏移',
    created_at       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_anno_source (username, source_filename) COMMENT '查某文档的所有标注',
    INDEX idx_anno_target (username, target_filename) COMMENT '查引用某文档的标注'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='关键语句标注表';
```

**查询示例**：
```sql
-- 查看某文档的所有标注
SELECT * FROM annotations
WHERE username = ? AND source_filename = ? ORDER BY position_start ASC;

-- 查看引用某文档的标注（"被引用于"）
SELECT * FROM annotations
WHERE username = ? AND target_filename = ? ORDER BY created_at DESC;
```

## 实体关系图

```
users (不变)
   │
   ├──< categories        (用户 → 分类树，parent_id 自引用)
   │
   ├──< documents (修改)  (用户 → 文档，新增 category_id)
   │         │
   │         └── category_id → categories.id（NULL=未分类）
   │
   └──< annotations       (用户 → 标注)
              │
              ├── source_filename → documents.filename
              └── target_filename → documents.filename（可空）
```

## 与现有表的关系

| 操作 | 表 | 关系 |
|:----:|----|------|
| 🖊 加字段 | `documents` | 新增 `category_id`，引用 `categories.id` |
| 🆕 新建 | `categories` | 通过 `username` 关联用户，`id` 被 `documents.category_id` 引用 |
| 🆕 新建 | `annotations` | 通过 `username` + `filename` 关联 `documents` |
